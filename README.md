# 2048

一个使用 Python 和 Pygame 编写的 2048 小游戏。玩家通过移动数字方块，让相同数字相撞并合并，目标是合成 2048 方块。

## 功能

- 4 × 4 游戏棋盘，支持方向键和鼠标滑动操作
- 方块移动、合并和新方块生成动画
- 实时显示当前分数、历史最高分和历史最高方块
- 自动保存最高分和最高方块
- 自动尝试使用 Windows 中文字体；未找到时使用 Pygame 默认字体

## 环境要求

- Python
- Pygame

## 安装与运行

在项目目录中安装 Pygame：

```bash
pip install pygame
```

启动游戏：

```bash
python 2048.py
```

## 操作方式

| 操作 | 功能 |
| --- | --- |
| ← / → / ↑ / ↓ | 向左、右、上、下移动方块 |
| 鼠标拖动 | 按拖动方向移动方块 |
| R | 重新开始 |
| Q | 退出游戏 |

点击开始界面上的“开始游戏”按钮进入游戏。相同数字的方块合并时会变为它们的总和；每次有效移动后，棋盘会生成一个新的 2 或 4 方块。合成 2048 即获胜；棋盘填满且无法继续移动时游戏结束。

## 项目文件

- `2048.py`：游戏逻辑、Pygame 界面、动画和输入处理。
- `highest_score.json`：游戏运行时用于保存历史最高分和历史最高方块；如果文件不存在，游戏会在保存记录时创建它。
